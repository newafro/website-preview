New Afro Studio

Manage the website

Sign in with GitHub to edit the New Afro website. Updates go to preview first, so the team can review changes before they appear on the public site.

Common actions:

  • Create or update an event, then review it on preview.
  • Publish a journal post with a hero image, gallery, and alt text.
  • Add an artist profile for the community page.
  • Use WhatsApp feedback to request fixes before production.

Preview site: preview.newafro.com

If sign-in fails, ask an administrator to confirm your GitHub access to newafro/website and the New Afro OAuth proxy.
